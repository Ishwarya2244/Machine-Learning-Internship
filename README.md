# Fake News Detection

**Description:**  Detects fake news using Machine Learning classification.  

**Tools/Libraries Used:**  Python, Pandas, scikit-learn, NumPy  

**How to Run: **
1. Install required libraries: `pip install -r requirements.txt` (if you have)  
2. Open `Fake_News.ipynb` in Jupyter Notebook  
3. Run the notebook step by step  

**Dataset:**  Dataset is large nd not included. You can download it from Kaggle.
